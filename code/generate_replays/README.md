# generate_replays

Generate replay sidecars for a directory of clip `.bk2` files.

This step is decoupled from scene detection: it replays each clip `.bk2`
and writes its sidecars. It works on the clips produced by
[`generate_clips`](../generate_clips/) as well as on clips generated by
artificial agents — any directory of `.bk2` files will do.

## Prerequisites

- A directory of clip `.bk2` files
- The game `stimuli/` directory (ROM, `data.json`, integration files)
- Python 3.10+

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python generate_replays.py \
    -i /path/to/mario.scenes \
    -sp /path/to/mario/stimuli \
    -nj 4 -v
```

| Flag | Description |
|------|-------------|
| `-i, --input` | Directory containing clip `.bk2` files, searched recursively (required) |
| `-sp, --stimuli` | Path to `stimuli/` (game ROM, integration files) (required) |
| `-m, --manifest` | Path to `clips_manifest.tsv` (default: auto-detected in `--input` or its parents) |
| `--skip_variables` | Skip writing per-clip `_variables.json` files |
| `--no-skip_first_step` | Keep the first movie step (on by default — each clip `.bk2` adds one extra post-reset frame on replay) |
| `--overwrite` | Regenerate sidecars even when they already exist |
| `-nj, --n_jobs` | Parallel workers (`-1` = all cores) |
| `-v` | Verbosity (`-v` INFO, `-vv` DEBUG) |

## The clips manifest

`generate_clips.py` writes a `clips_manifest.tsv` at the dataset root. It
records the scene-detection metadata that cannot be recovered from a
`.bk2` alone — `outcome`, `phase`, and `source_bk2`. When this file is
found (or passed via `-m`), those fields are merged into each
`_summary.json`.

For clip datasets without a manifest (e.g. artificial-agent clips), the
sidecars are still generated; the manifest-only fields are simply omitted.

## Output

For each clip `.bk2`, four sidecars are written next to it:

```
sub-01_ses-001_task-mario_level-w1l1_scene-0_clip-00100000000122.bk2
sub-01_ses-001_task-mario_level-w1l1_scene-0_clip-00100000000122_recording.mp4
sub-01_ses-001_task-mario_level-w1l1_scene-0_clip-00100000000122.state
sub-01_ses-001_task-mario_level-w1l1_scene-0_clip-00100000000122_variables.json
sub-01_ses-001_task-mario_level-w1l1_scene-0_clip-00100000000122_summary.json
```

- `_recording.mp4` — Video playback of the clip (with audio)
- `.state` — Gzipped emulator RAM at clip entry
- `_variables.json` — Frame-by-frame game variables
- `_summary.json` — Metadata (entities, frame range, gameplay stats, and —
  when a manifest is available — scene outcome / phase / source replay)
